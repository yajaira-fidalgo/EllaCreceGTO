# Ella Crece GTO 📱

Aplicación móvil desarrollada en Android Studio con Kotlin y Jetpack Compose.

## 🚀 Descripción
Proyecto para la comunidad de Guanajuato con autenticación e integración con Firebase.

## 🛠️ Tecnologías utilizadas
- Kotlin
- Jetpack Compose
- Firebase Firestore & Auth
- Gradle (Kotlin DSL)
